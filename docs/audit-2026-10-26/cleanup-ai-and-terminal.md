# 清理狀態、AI 快取與官方 TUI

驗證程式版本：`c9e694d18224847d14418f6bd0a4743e90c9fee5`。已備份前版並更新本機 MoPanel；Mole 引擎仍為原本的 1.62。

## 操作狀態

重新掃描時立即丟棄前一輪清單、選取、結果及畫面紀錄。掃描完成才顯示本次結果；預覽檔時間早於本次掃描則拒絕載入。進入清理頁不會自動讀回磁碟上的舊預覽。一般系統清理全部成功時清空檢視，顯示「清理成功」與重新掃描入口；未勾選的檔案仍留在原處。部分失敗或取消時保留未完成項目與原因，不顯示全部成功。

容量分為本次預覽列出、已選清理、可自行勾選與保留項目；整體預覽容量避免重算父子目錄。這沒有擴大一般系統清理的可刪除範圍。

本次查看官方 GUI 時，11.37 GB 是掃描總量，預選約 3.49 GB；垃圾桶約 6.19 GB 中預選 2.42 GB，開發工具約 3.34 GB 中預選 639 KB，App 快取約 1.3 GB 中預選 1.06 GB。當時 MoPanel 預選約 39.2 MB；約 747 MB 的 Chrome 舊框架版本列為手動管理。官方 GUI 還有部分項目沒有出現在已安裝 CLI 的 clean-list.txt。兩者的候選來源、保留規則與垃圾桶處理方式並不相同；上述數值會隨檔案變化和非同步估算更新，不能視為受控的同時掃描基準，也沒有為了對齊數字放寬刪除條件。

## AI 清理

系統清理右上角新增月亮圖示「AI 清理」，在同一主視窗切換頁面。手動掃描 Claude、Codex 桌面版、Cursor、Windsurf、Qoder、OpenCode 的 27 個固定快取位置，使用 macOS 檔案 API，沒有對應 CLI 指令。經核對可重建且工具未執行的項目預選；清理使用 NSWorkspace.recycle。執行前重查身分、擁有者、權限與工具程序。

只處理指定 Cache／Code Cache／GPU 與 Dawn 快取，以及 OpenCode 的 cache 位置。對話、登入資料、設定、技能、模型及整個工具資料夾皆不列為清理目標。Codex 只處理 Library/Caches 下六個已確認的 Chromium 快取，不處理 .codex。若已有自訂 Mole 保護清單或無法驗證它，本頁保守保留全部快取；原生 wildcard 保護清單轉接尚未實作。不新增背景掃描或計時器。

此頁是 AI 快取清理與既有 Git 工作副本管理的入口，沒有宣稱等同官方月亮的所有功能。舊工作階段、CLI 舊版本、工具整包卸載及資料庫壓縮尚未納入。官方月亮另有這些能力，見 [官方文件](https://mole.fit/docs)與[開發紀錄](https://mole.fit/blog/testing-ai-tools-for-mole)。

本機唯讀掃描實際列出六項、約 60.2 MB 的 Codex 快取。因 Codex 正在執行，六項均未勾選，原因可展開查看；沒有清理它們。Git 頁面也補上白話說明：worktree 是同一專案的額外工作副本，可能包含 AI 任務的未提交工作，須經既有 Git 保護檢查。

## 大型 TUI 視窗

設定中的官方儀表板執行 `mo status`，現在顯示於獨立、可縮放及全螢幕的原生視窗。只有此唯讀儀表板改為獨立視窗，維護進度仍留在主畫面。重複點擊沿用同一視窗與程序，關閉會取消受控子程序並釋放終端；啟動前停止既有監控，避免重複收集。設定已移除「MoPanel 新實作」括號標示。

## 驗證與範圍

- 完整 release 流程通過 270 項 XCTest（零失敗／略過）、20 項 fixture、52 項原生介面斷言／31 次已驗證按鈕派送、17 項 Guardian 與 App／ZIP strict 驗證。
- TUI 的原生測試檢查獨立視窗、大型實際 viewport、真 PTY 輸入與尺寸變更、重開共用程序，以及關閉後取消。套裝測試版及安裝後的真實 Mole TUI 都已操作確認。

- 沒有清理使用者真實檔案、清空垃圾桶、移除 AI 對話、變更啟動或權限設定。私人清單只留本機。前輪 CPU／記憶體數據仍屬其原版本，本輪未重做長時間資源觀察。
