# 分類清理與權限結果修正

程式版本：`6970c52`。保留 MoPanel 的側邊導覽、暖色玻璃與 macOS 控制項，將維護頁改為先選項目、再執行的操作方式。

## 清理與權限

使用者回報 73 項成功移至垃圾桶、1 個快取資料夾被拒絕。唯讀檢查確認：擁有者雖為目前使用者，macOS 仍拒絕開啟該資料夾；擁有權不等於可存取或可移動。沒有更改權限、要求全面磁碟存取或強制刪除。

- 新的預檢會確認可讀取、可移動及鎖定狀態。無法讀取的項目取消預選，容量顯示未能讀取，歸入手動管理。
- 分類列顯示勾選數、已選／總容量、用途與展開控制；原生 checkbox 支援部分勾選。
- 展開後直接勾選檔案。右側可看詳細原因或在 Finder 顯示；右鍵可保留本次項目、複製路徑。
- 底部固定全選、全不選、建議與主要清理按鈕。一般清理將選取檔案移至垃圾桶，不再增加一層相同的預覽／確認。
- 部分失敗會分開列出成功、未處理與尚未處理數量。失敗項目保留、取消選取並阻止直接重試；每次處理都更新進度，包括略過的項目。
- 舊預覽中已不存在的項目不會再次列出；結果已變動時取消選取並要求重新掃描。

## 相關操作頁

卸載使用單一清單：選取 App 立即展開相關檔案，底部固定移除操作；個人資料維持保守預設，技術選項收在更多選項。

Installer、Purge、Slim 的受驗證 Mole 選單投影移到主頁，底部固定下一步與最後確認；保留終端畫面在背景掛載，確保每個勾選仍經 Mole 回讀確認。永久刪除的最後確認沒有省略。

更新頁以 App、版本與動作為主，來源、路徑及更新條件收合。啟動頁保留登入與背景 App 的直接清單，搜尋可直接使用，其他服務及來源細節可展開。Git 項目的檢查明細收合，移除前的保護驗證與確認保留。

## 驗證

254 項 XCTest、20 項 fixture 檢查、46 項原生 UI 斷言、29 次已驗證控制項派送、17 項 Guardian 測試與 App／ZIP 簽章完整性檢查通過。

生產 FileReviewController 使用 nonce 命名的合成 App、快取及偏好設定完成 24 項檢查，包含不可讀取、掃描過期、執行中權限變動、部分成功及未勾選個人資料保留；3 次實際垃圾桶移動均只涉及新建測試檔案，之後清除測試產物。Mole 選單控制器 11 項檢查通過。

已在最終版本的獨立 fixture App 中實際點擊：分類與部分勾選、容量回讀、手動管理原因、卸載相關檔案展開，以及安裝檔主頁勾選、Mole 回讀、最後確認和完成摘要。沒有執行使用者真實清理、卸載、更新或啟動設定變更。

本次沒有新增取樣計時器，也沒有重跑長時間效能觀察。預檢只開啟選定資料夾本身，不遞迴檢查所有子項目；執行時 macOS 仍可能拒絕個別移動，介面會保留實際原因，不能宣稱所有權限情境都已通過。
