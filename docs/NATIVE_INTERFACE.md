# 原生介面與監控面板

## 抽屜式導覽列

展開寬度為 230 pt，收合後保留 72 pt 的固定圖示區。圖示和文字使用固定尺寸，文字區在裁切範圍內水平滑入／滑出，主內容跟隨欄位邊界左右移動，不對整片介面做縮放。開合使用 0.24 秒緩入緩出，減少動態效果開啟時停用。

切換按鈕位於側欄上方右側，收合時回到圖示區中央。按鈕是 30 × 30 pt 的方形原生圖示按鍵，沒有工具列的橢圓外框，也不保留選取狀態或焦點光圈。左上角改用 App 自身的黑白 M 圖示；頁面選取採低對比背景與細框。圖示模式仍提供完整名稱、工具提示及輔助使用標籤。導覽支援滑鼠、輔助使用按壓與鍵盤上下方向操作。

## 光影與材質

背景以系統石墨／淺色底，搭配暖金與灰藍的靜態光暈。主要互動色改為暖金，網路與圖表採低飽和輔色；側欄不再使用大面積亮藍選取色。側欄使用 AppKit sidebar 材質，卡片使用原生互動 Liquid Glass。減少透明度時退化為不透明表面；自訂動畫遵從減少動態效果。

背景沒有持續運轉的動畫計時器。互動集中在抽屜開合、導覽列懸停／按壓、系統玻璃反應與監控數字更新。

## Mole 式選單列面板

從設定的「低負載監控 → 在選單列顯示即時監控」開啟既有選單列入口。面板包含健康分數與硬體摘要、CPU、GPU、記憶體、磁碟可用空間、網路、風扇讀值、電池及最多五個高用量程式。面板可捲動以適應螢幕高度。

資料沿用總覽既有的單一 Mole Status 串流，不新增 Stats 引擎或另一個採樣迴圈。最多保留 120 筆趨勢，迷你圖只畫最近 40 筆；GPU 缺值、負值、未回報的溫度／風扇／電池會顯示未提供，不補造數字。已確認有風扇且回報 0 RPM 時保留 0 RPM。磁碟空間採官方已用／總量推算，不當成可清理容量。

面板沒有未實作的風扇模式、低延遲網路或鏡頭／麥克風控制。系統工具入口連到既有功能；保持喚醒狀態來自原生工具控制器。

## 驗證範圍

自動介面流程加入實際開合按鈕與導覽列切頁，合計 23 次公開 accessibility 按壓及效果驗證。側欄寬度取自實際原生材質視圖的 bounds，不以被裁切文字的輔助使用合併外框推算。切換鍵檢查包含正常按鍵狀態、無持續高亮、無焦點光圈及無邊框。

另以明確的合成資料模式檢查實際視窗中的深色／淺色外觀、圖示區、M 圖示、按鈕位置及監控卡片。開發預覽最多 300 秒，標準 smoke driver 會移除預覽參數。預覽期間的語言、外觀與路徑修改不寫入正常設定。

此批驗證不等於全專案所有控制項、真實破壞性操作／權限、1／8／24 小時常駐或 Instruments 驗收。全面審查剩餘項目見 [PRODUCT_READINESS_AUDIT.md](PRODUCT_READINESS_AUDIT.md)。
